Ungroup agent demo: six ONNX agent seats through web/src/engine.js

Loads onnxruntime-web from jsDelivr (needs network), the exported policy from ../models/, plays self-play rounds with paired seeds through the JS engine (seat i observes with game.observe(i), the agent samples the masked logits, game.setInput(i, ...), game.step(decideEvery)) and prints the mean progress per seat, the same quantity as rl/play_v2.py eval "self-play". Query parameters: ?auto=1&model=v9_150&games=16&seed=5000&det=0.
